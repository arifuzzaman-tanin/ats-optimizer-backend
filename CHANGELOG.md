## [0.1.1] - 2026-10-21

### Added

- Expanded full-stack, database, integration, reliability, and document-processing
  skill recognition for production SaaS job descriptions.
- Added regression coverage for the Remarcable Full Stack Software Engineer role.

## [0.1.0] - 2026-10-16

### Added

- Standalone `ats_optimizer` package with typed result models.
- Deterministic text analysis and JSON-compatible serialization.
- Optional local PDF extraction through the `pdf` extra.
- Package, compatibility, build, and installation tests.
- PyPI build and Trusted Publishing documentation.
- Public-domain dedication under the Unlicense.

### Compatibility

- Preserved catalogue matching, score rounding, score bands, and Flask output.
- Retained the legacy `skill_extractor` module for deployment compatibility.
